Welcome to Growthcraft. Growthcraft is a collection of Minecraft mods that adds an extra layer of immersion into the
world of Minecraft. Growthcraft adds apple trees, honey, hops, grapes that grow along rope, cheese, yogurt, ice cream,
butter, rice, ale, wine, juice, cider, kumis, and sake. Many drinks can also be aged or fermented further for stronger
effects.

## Getting Started

There are multiple starting points to Growthcraft. The in-game manual is the primary gameplay reference for Growthcraft
26.1.2 and includes getting started notes, recipes, machine guidance, and release information.

This repository is the active porting workspace for Minecraft 26.1.2. Internal porting notes live under the local
`docs/` directory and are intentionally ignored by Git.

### IDE Run Configurations

This project uses the NeoForge ModDev plugin. IntelliJ run configurations are generated by the `genIntellijRuns` task,
not by the standard Gradle `createLaunchScripts` task.

- Generate IDEA run configs: `./gradlew genIntellijRuns`
- VS Code users can run: `./gradlew genVSCodeRuns`

After generation, reload the Gradle project in IntelliJ if run configs do not appear immediately.

mods added cheese, yogurt, ice cream, sake, rice, and thistle crops. When we first rolled out the thistle crop, it was
known to wildly grow and take over entire worlds.

## Versioning Policy

We maintain the mod version in `gradle.properties` using a Minecraft-version-prefixed scheme, such as `26.1.2.x`.
Whenever a significant feature or behavior change is completed, increment the version:

- Update `mod_version` in `gradle.properties`.
- Update the version badge at the top of `README.md` and the History section's Latest/Stable lines.
- Include the version bump in the same PR as the feature or immediately after.

Use patch-level bumps for additive features, fixes, and small changes. Consider minor/major schema changes if we later
adopt broader semver rules.
